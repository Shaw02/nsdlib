NSD.Lib – サウンドドライバの使い方

概要

本ページでは、NSD.Lib サウンドドライバを実際の NES アプリケーションから どのように組み込んで使用するかを説明します。

API の詳細仕様（関数一覧・呼び出し規約・内部構造）については、 API リファレンスを参照してください。

基本的な使用手順

NSD.Lib の基本的な利用手順は、以下の流れになります。

  1. ドライバの初期化
  2. （必要に応じて）DPCM 情報の設定
  3. BGM / SE データの再生開始
  4. １フレームごとの再生更新

ドライバ初期化

アプリケーション起動時に、サウンドドライバを初期化します。

初期化処理の詳細仕様や注意点は、 nsd_init() を参照してください。

再生更新モデル

NSD.Lib のサウンドドライバは、自律的に再生処理を進める方式ではありません。

ユーザーアプリケーション側から 1 フレームごとに更新関数を呼び出す ことで、 BGM や効果音の再生が進行します。

通常は nsd_main() を使用しますが、 BGM と SE を異なるメモリバンクに配置する構成では、 個別更新用の関数を使用します。

詳細は以下の API を参照してください。

  • nsd_main()
  • nsd_main_bgm()
  • nsd_main_se()

BGM / SE の再生

BGM および効果音は、MML コンパイラで作成したデータを指定して再生します。

再生・停止・一時停止などの制御は、API リファレンスの 関数一覧を参照してください。

サンプルコード

以下に、C 言語での基本的な使用例を示します。 

#define	__NES__

#include	<nes.h>
#include	"..\..\include\nsd.h"

/* コンパイラが生成した曲データ */
extern	const	char		Test_BGM0[];
extern	const	nsd_dpcm	Test_DPCMinfo[];

//メインルーチン
void	main()
{
	/* サウンドドライバの初期化　*/
	nsd_init();

	 /* DPCM 情報の設定（使用しない場合は、不要） */
	nsd_set_dpcm(Test_DPCMinfo);	

	/* BGM 再生開始 */
	nsd_play_bgm(Test_BGM0);

	while(1){
		/* １フレーム毎に呼び出す（NMI割り込みでやっても良い） */
		nsd_main();	

		/* VBlank 待ち */
		waitvblank();
	}
}

※ 完全なサンプルコードは、サンプルフォルダ内のソースを参照してください。
