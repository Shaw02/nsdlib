NSD.Lib – NES Sound Driver & MML Compiler

Overview

NSD.Lib は、Nintendo Entertainment System (NES / Famicom) 向けの
サウンドドライバ（音源制御ライブラリ）および MML コンパイラです。
ゲームへの組み込みとチップチューン・NSF 音楽制作の 両方の用途をサポートします。

NSD.Lib is a sound driver and MML compiler for the Nintendo Entertainment System (NES), supporting both game integration and chiptune/NSF music production.

Sound Driver for Game Integration

NSD.Lib のサウンドドライバは、cc65 / ca65 向けのオブジェクトライブラリとして 設計されており、ユーザーアプリケーションから BGM や効果音を制御できます。

The sound driver is provided as an object library for NES development toolchains, allowing game code to control music and sound effects.

ゲームループにおけるフレーム単位の呼び出しモデルなど、制約のある 環境でも効率的に動作する設計になっています。

→ サウンドドライバの使い方 / API リファレンス

Chiptune & NSF Music Creation

MML コンパイラ nsc.exe を使うと、MML から NSF（NES Sound Format）や ca65 用のアセンブリ言語ソースを生成できます。

Using the MML compiler, you can convert MML to NSF music files or assembly sources for embedding.

→ MML コンパイラの使い方

Key Features

  • NES APU（RP2A03）向けサウンドドライバ
  • MML → NSF 生成対応
  • MML → ca65 アセンブリ変換
  • ゲーム埋め込みと単体音楽制作の両対応
  • cc65 / ca65 ツールチェーンとの互換性
  • コンパクトで再生負荷を抑えた実装

• NES APU sound driver
• Output NSF (NES Sound Format)
• Convert MML to ca65 assembly
• Designed for both game integration and chiptune
• Compatible with cc65 / ca65 toolchains
• Compact and cycle-conscious implementation
