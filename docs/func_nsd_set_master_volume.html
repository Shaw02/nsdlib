トップ＼ 使い方＼ 音源ドライバー＼ 関数リファレンス＼

nsd_set_master_volume()

定義（Define）

        void    __fastcall__    nsd_set_master_volume(char master_volume );

引数（Inputs）

char master_volume … マスターボリュームを、０（無音）～１５（最大）で設定します。

戻り値（Outputs）

無し（no output）

内容（Contents）

引数char master_volumeでマスターボリュームを設定します。

三角波、⊿ＰＣＭには音量が無いため、以下の処理を行います。

０～５
無音にします。
６～１４
ゲートクオンタイズを調整します。音調×マスターボリューム÷１６
１５
何も処理しません。

注意（Notes）

三角波、⊿ＰＣＭには音量が無いため、不自然になります。
その旨を留意して、ご利用ください。
